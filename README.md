# UART Protocol using VHDL

This project implements a UART (Universal Asynchronous Receiver Transmitter) communication protocol using VHDL.

## Features
- Serial data transmission
- Serial data reception
- 8-bit data communication
- Transmitter and receiver
- UART simulation

## Tools Used
- VHDL
- EDA Playground
- GHDL

## Files
- `uart_protocol.vhd` – UART design
- `uart_protocol_tb.vhd` – UART testbench
